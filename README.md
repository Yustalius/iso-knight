# Последний караул — изометрический рыцарь · Стрельбище Нокс — солдат

Два играбельных прототипа в духе Project Zomboid: 3D-персонаж под ортографической камерой 30° (изометрия 2:1), пиксельный рендер, процедурная анимация и немного физики.

- `index.html` — рыцарь во дворе с соломенными чучелами.
- `soldier.html` — солдат армии США образца 1993 года (как военные в Zomboid) на стрельбище: целиться и стрелять как в PZ.

Опубликованные версии (приватные, доступ через Share): рыцарь — https://claude.ai/artifact/EFSAWvQ3tujLhjyCWCy7DH, солдат — https://claude.ai/artifact/8nZYDCyXb6VxBHCdWZyywk.

## Запуск

```sh
npm start            # рыцарь: http://127.0.0.1:8777, солдат: http://127.0.0.1:8777/soldier.html
USE_CDN=1 npm start  # как в опубликованной версии: three.js с jsDelivr
```

Рыцарь: WASD, Shift — бег, ЛКМ/пробел — удар (повтор — серия), ПКМ — щит и поворот к курсору, F — щит без поворота, T — замедление ¼×, Q/E — поворот камеры, колесо — масштаб. На телефоне: тап по земле и кнопки.

Солдат: WASD, Shift — бег (винтовка «на грудь»), **ПКМ держать — вскинуть винтовку и развернуться к курсору, ЛКМ — выстрел**, ЛКМ/пробел без прицела — толчок винтовкой, R — перезарядка, X — режим огня (одиночный / очередь ×3 / автомат), C — присесть, T — замедление, Q/E — камера, колесо — масштаб. На телефоне: «Прицел» (автонаведение на ближайшую мишень, касание выбирает точку), «Огонь», «Перезар.», «Толчок».

### Стрельба как в Project Zomboid

- Пока ПКМ зажата, солдат вскидывает винтовку к плечу и поворачивается к курсору (корпус доворачивает ствол на ±60° сразу, ноги догоняют), идёт медленно, бег невозможен; камера смещается к точке прицела (отключается в настройках).
- Круг прицела — это реальный конус разброса на дистанции курсора: широкий сразу после вскидывания, сужается, пока стоишь и держишь прицел, расширяется от ходьбы, разворота и каждого выстрела (очередь «раздувает» его); в приседе точнее.
- Мишени в конусе обводятся контуром цвета шанса попадания (красный → жёлтый → зелёный), процент — у курсора. Шанс считается честно: доля из 48 лучей конуса, попадающих в силуэт.
- Пуля — быстрый снаряд с трассером, проверяемый по геометрии: силуэты, гонги и банки — аналитически, остальное — рейкастом. Попадание оставляет пробоину и осколки по материалу (щепки, искры, земля, бетонная крошка, листья).
- Мишени: армейские падающие силуэты (сбитый падает на шарнире и через 2,6 с поднимается мотором), стальные гонги на цепях (маятник + кручение, звон), жестяные банки (твёрдые тела, через 5 с возвращаются на место).
- Перезарядка по фазам: пустой магазин выпадает и остаётся лежать, рука лезет в подсумок, досылает новый, бьёт по затворной задержке (если магазин был пуст). Гильзы вылетают вправо и раскатываются по земле. Звук синтезируется на лету (WebAudio), без файлов.

## Устройство

| Файл | Что внутри |
| --- | --- |
| `src/knight-model.js` | Модель рыцаря: геометрия и текстуры 64×64 из прототипа GPT (`reference/`), отражена (меч в правой руке), добавлены шарнирные полы сюрко и задняя пола. Один `SkinnedMesh`, 22 кости. |
| `src/knight-rig.js` | Процедурная анимация. Походка считается из реальной локальной скорости: каденс, длина шага и доля опоры зависят от скорости, опорная стопа едет назад ровно со скоростью тела (не скользит), работает шаг вбок/назад и переступание при развороте на месте. Ноги и руки — двухзвенная IK. Удары — кривые Эрмита для кисти, клинка и корпуса, клинок отстаёт от кулака (хлёст). Пружины: полы сюрко (бёдра — коллайдеры), инерция щита, отдача при попадании. |
| `src/world.js` | Двор: плиты и стены из инстансов, трава, деревья, реквизит, знамя из той же ткани, что сюрко. Чучела — 2D-маятник на пружине + свободное вращение. |
| `src/main.js` | Рендер, камера с привязкой к пиксельной сетке, ввод, игровой цикл, частицы, хит-стоп, отладочный API `window.__knight`. |
| `src/textures.js` | Общие 64×64 пиксельные текстуры (узоры рыцаря + камуфляж M81/DCU, стропа, кожа, фанера, бетон, рабица…). |
| `src/rigid-kit.js` | Конструктор жёстко-скиннованных персонажей: кости, примитивы, запекание в один `SkinnedMesh`. |
| `src/rig-core.js` | Общая механика ригов: кривые Эрмита, пружины, двухзвенная IK, стопа «пятка–носок», походка от скорости (с приседом). |
| `src/soldier-model.js` | Солдат 1993 г.: BDU M81 с закатанными рукавами, каска PASGT (свой купол с полями), бронежилет PASGT, разгрузка ALICE, ботинки, M16A2 с изогнутым магазином; ремень винтовки — отдельная лента. Один `SkinnedMesh`, 23 кости, ~4,2 тыс. треугольников. Пропорции коренастые, как у рыцаря, камуфляж — крупные пятна без пиксельного шума, чтобы форма читалась при пикселе 2×. |
| `src/soldier-rig.js` | Анимация солдата: походка рыцаря + позы винтовки (у бедра / «порт» на бегу / у плеча / перезарядка / толчок) в пространстве груди, IK обеих рук на рукоять и цевьё, щека на прикладе, стойка вполоборота, отдача на пружинах, ремень на верлете, болтающиеся подбородочные ремни и фляга. |
| `src/range-world.js` | Стрельбище: огневой рубеж, мешки с песком, бетонные блоки, вышка, палатка, ограда с «егозой», вал-пулеулавливатель, флаг «Браво», дорога; мишени с физикой и `trace()` для пуль. |
| `src/gunfx.js` | Вспышка и свет выстрела, трассеры, гильзы и магазины (твёрдые тела), пробоины, частицы по материалу. |
| `src/sfx.js` | Процедурный звук: выстрел с эхом, сухой щелчок, магазин, затвор, звон гонга, гильзы, попадания. |
| `src/soldier-main.js` | Ввод, прицеливание, разброс, режимы огня, перезарядка, контур целей (маска + проход по экрану), круг прицела, HUD, камера, отладочный API `window.__game`. |
| `tools/serve.mjs` | Локальный сервер; оборачивает страницы `*.html` в тот же каркас, что и хост артефактов. |
| `tools/shots.cjs` | Детерминированные headless-скриншоты по плану (Playwright), `PAGE=soldier.html` — для солдата, см. CLAUDE.md. |
| `reference/gpt-isometric-knight/` | Исходный прототип GPT «Последний караул» для сравнения (без node_modules). |
| `vendor/three/` | three.js 0.180.0 (MIT), только нужные файлы. |

## Публикация артефакта

`index.html` (или `soldier.html`) + `src/*.js` публикуются как многофайловый артефакт; в нём `importmap` указывает на jsDelivr.
