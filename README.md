# Последний караул — изометрический рыцарь

## Симуляция и боты (`sim/`)

Правила будущей игры (Godot 4, C#) как отдельная .NET-библиотека без графики. Её одинаково используют игра, арена ботов и обучение нейросетей:
детерминированный тик 30 Гц, 2.5D-видимость и укрытия, винтовка из прототипа солдата, восприятие с туманом войны, генератор карт,
боты на правилах с девятью стратегиями и командиром отряда, составы от 1×1 до 10×10, реплеи. Замысел — [`docs/bots.md`](docs/bots.md),
устройство, API, числа и замеры — [`docs/sim.md`](docs/sim.md).

```sh
cd sim
dotnet test Squad.Tests
dotnet run --project Squad.Tools -c Release -- arena --scenario scenarios/asym-7v5.json --matches 200 --swap
dotnet run --project Squad.Tools -c Release -- render --scenario scenarios/flank-forward-defenders.json --seed 3 --to 40 --every 5
dotnet run --project Squad.Tools -c Release -- render --scenario scenarios/asym-7v5.json --seed 4 --to 300 --every 0.0333334 --frames out/f   # кадр на тик, для ffmpeg
```

## 3D-просмотр матчей (`game/`, Godot 4.7 .NET)

Godot-проект подключает `sim/` напрямую и рисует матч ботов в изометрии: `Truth` и `Events`, интерполяция между тиками.
Пока это просмотрщик, а не игра. Графика переносится из концепта «Стрельбище Нокс» по этапам [`docs/graphics-task.md`](docs/graphics-task.md),
контактные листы «концепт | Godot» — в `docs/graphics/`.

- Бойцы — модель концепта: синие — M81, красные — OPFOR. Модель выгружается из three.js в `game/art/*.glb`
  (`node tools/export-art.cjs`, исходники модели — копии из ветки концепта в `game/art-src/`) и грузится в рантайме через `GltfDocument`,
  без импорта в редакторе. Анимация процедурная, перенесена с `soldier-rig.js` на C# (`game/SoldierRig.cs`, `game/RigMath.cs`):
  ствол всегда смотрит по `AimYaw`/`AimPitch` симуляции, ноги догоняют его с запаздыванием до ±60°.
- `--showcase stand|aim|crouch|walk|run|sneak|reload|tactical|fire|turn` — без матча, два бойца в позах как в планах `shots.cjs` концепта,
  для крупных планов рядом с кадрами концепта (`--resolution 1100x760`, как у страницы концепта). `python -I tools/pairsheet.py` собирает лист.

```powershell
powershell -File game\run.ps1 --scenario big-10v10 --seed 4      # путь к Godot по умолчанию в скрипте, иначе -Godot <exe>
```

Пробел — пауза, `.` — тик, `+`/`-` — скорость, `R`/`N` — заново / следующий сид, `[`/`]` — сценарий, `F` — следить за бойцом,
`H` — срезать высокие стены, `Tab` — отладочный слой (подписи `L`, конусы обзора `C`, справка), WASD/ПКМ — камера, Q/E — поворот, колесо — масштаб.
`--shots 5,20` сохраняет кадры в `sim/out/godot/` и закрывает окно — так проверять изменения без человека; кадры при этом идут
фиксированным шагом 1/60 с, независимо от скорости машины.

## Прототип рыцаря (three.js, референс)

Играбельный прототип в духе Project Zomboid: 3D-персонаж под ортографической камерой 30° (изометрия 2:1), пиксельный рендер, процедурная анимация и немного физики.

Опубликованная версия: https://claude.ai/artifact/EFSAWvQ3tujLhjyCWCy7DH (приватная, доступ через Share).

### Запуск

```sh
npm start            # http://127.0.0.1:8777, three.js берётся из vendor/, интернет не нужен
USE_CDN=1 npm start  # как в опубликованной версии: three.js с jsDelivr
```

Управление: WASD, Shift — бег, ЛКМ/пробел — удар (повтор — серия), ПКМ — щит и поворот к курсору, F — щит без поворота, T — замедление ¼×, Q/E — поворот камеры, колесо — масштаб. На телефоне: тап по земле и кнопки.

### Устройство

| Файл | Что внутри |
| --- | --- |
| `src/knight-model.js` | Модель рыцаря: геометрия и текстуры 64×64 из прототипа GPT (`reference/`), отражена (меч в правой руке), добавлены шарнирные полы сюрко и задняя пола. Один `SkinnedMesh`, 22 кости. |
| `src/knight-rig.js` | Процедурная анимация. Походка считается из реальной локальной скорости: каденс, длина шага и доля опоры зависят от скорости, опорная стопа едет назад ровно со скоростью тела (не скользит), работает шаг вбок/назад и переступание при развороте на месте. Ноги и руки — двухзвенная IK. Удары — кривые Эрмита для кисти, клинка и корпуса, клинок отстаёт от кулака (хлёст). Пружины: полы сюрко (бёдра — коллайдеры), инерция щита, отдача при попадании. |
| `src/world.js` | Двор: плиты и стены из инстансов, трава, деревья, реквизит, знамя из той же ткани, что сюрко. Чучела — 2D-маятник на пружине + свободное вращение. |
| `src/main.js` | Рендер, камера с привязкой к пиксельной сетке, ввод, игровой цикл, частицы, хит-стоп, отладочный API `window.__knight`. |
| `tools/serve.mjs` | Локальный сервер; оборачивает `index.html` в тот же каркас, что и хост артефактов. |
| `tools/shots.cjs` | Headless-скриншоты по плану (Playwright), см. CLAUDE.md. |
| `reference/gpt-isometric-knight/` | Исходный прототип GPT «Последний караул» для сравнения (без node_modules). |
| `vendor/three/` | three.js 0.180.0 (MIT), только нужные файлы. |

### Публикация артефакта

`index.html` + `src/*.js` публикуются как многофайловый артефакт; в нём `importmap` указывает на jsDelivr.
